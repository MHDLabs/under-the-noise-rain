## 🛰️ دربارهٔ داستان

جهان دیگر شبیه گذشته نیست. پس از فروپاشی نظمِ آشنا، جاده‌ها ناامن شده‌اند، ارتباط‌ها از کار افتاده‌اند و هر صدای ناشناسی می‌تواند معنایی بیشتر از یک خش‌خش ساده داشته باشد.

مهدی در میان خرابه‌ها به دنبال ابزارهای ارتباطی، آنتن‌ها و ردّی از شبکه‌ای خاموش می‌گردد. در این مسیر، آشنایی با مهیا ماجرا را از یک تلاش ساده برای زنده‌ماندن فراتر می‌برد.

**«زیر بارانِ نویز»** قصه‌ای دربارهٔ تنهایی، اعتماد، بقا و پیدا کردن یک صدای انسانی در میان هزاران فرکانس مرده است. 🌫️

## 📴 مطالعه بدون اینترنت چطور کار می‌کند؟

برنامه از **Service Worker** و Cache مرورگر استفاده می‌کند:

1. در اولین بازدید، فایل‌های اصلی برنامه دریافت و در حافظهٔ کش ذخیره می‌شوند.
2. فصل‌ها هنگام دریافت موفق، در کش محتوای برنامه قرار می‌گیرند.
3. در بازدیدهای بعدی، اگر اینترنت در دسترس نباشد، نسخهٔ کش‌شدهٔ فایل‌ها و فصل‌های دریافت‌شده می‌توانند نمایش داده شوند.

**توجه:** برای اینکه یک فصل را آفلاین بخوانید، باید آن فصل قبلاً با موفقیت بارگذاری و کش شده باشد. آفلاین بودن به معنی دریافت خودکار تمام فصل‌ها پیش از اولین بازدید نیست.

## 🛠️ اجرای محلی

این پروژه با **HTML، CSS و JavaScript خالص** ساخته شده و برای اجرای نسخهٔ وب به مرحلهٔ Build یا نصب وابستگی‌های npm نیاز ندارد.

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/MHDLabs/under-the-noise-rain.git
cd under-the-noise-rain
```

سپس یک وب‌سرور محلی اجرا کنید:

```bash
python3 -m http.server 8080
```

حالا در مرورگر باز کنید:

```text
http://localhost:8080
```

> 💡 باز کردن مستقیم `index.html` هم ممکن است؛ اما بعضی مرورگرها درخواست‌های `fetch` در مسیر `file://` را محدود می‌کنند. برای تجربهٔ مطمئن‌تر، از وب‌سرور محلی استفاده کنید.

## 🗂️ ساختار مخزن

```text
under-the-noise-rain/
├── assets/                     # آیکون‌ها، لوگو و قلم‌های محلی
├── chapters/
│   ├── chapter-00.md           # متن فصل‌ها
│   └── manifest.json           # فهرست و ترتیب فصل‌ها
├── css/
│   ├── fonts.css               # تعریف قلم‌ها
│   ├── style.css               # ظاهر خواننده
│   └── themes.css              # تم‌ها
├── js/
│   ├── app.js                  # منطق اصلی رابط
│   ├── chapters.js             # بارگذاری و نمایش فصل‌ها
│   └── settings.js             # تنظیمات مطالعه
├── app-update.json             # تنظیمات به‌روزرسانی اپ
├── index.html                  # نقطهٔ ورود خواننده
├── manifest.webmanifest        # تنظیمات PWA
├── privacy.html                # سیاست حریم خصوصی
├── sw.js                       # Service Worker و کش آفلاین
├── poster.png                  # پوستر پروژه
└── under-the-noise-rain.apk    # نسخهٔ اندروید
```

## ✍️ افزودن فصل جدید

برای اضافه‌کردن فصل:

1. فایل فصل را در پوشهٔ `chapters/` بسازید؛ برای نمونه `chapter-41.md`.
2. مشخصات فصل شامل شناسه، عنوان و نام فایل را به انتهای آرایهٔ `chapters` در `chapters/manifest.json` اضافه کنید.
3. تغییرات را روی شاخهٔ `main` ثبت و Push کنید.
4. پس از انتشار نسخهٔ جدید توسط GitHub Pages، فصل در فهرست خواننده نمایش داده می‌شود.

نمونهٔ ورودی در فایل manifest:

```json
{
  "id": "chapter-41",
  "title": "عنوان فصل جدید",
  "file": "chapter-41.md"
}
```
